PhotoSplice portable mode

While this file sits next to photosplice.exe, PhotoSplice keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the PhotoSpliceData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move PhotoSplice with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Photosplice) instead.
If PhotoSpliceData can't be written (for example on a read-only drive), PhotoSplice says so and
uses %APPDATA%\Photosplice instead.
