# Filter Gallery textures

Relief textures for the Filter Gallery's Texturizer, Rough Pastels, Underpainting, Conté Crayon
and Glass: Blocks, Brick, Burlap, Canvas, Sandstone and Tiny Lens.

Each `.r8` file is a 128 × 128 grey height map: 16 384 bytes, one byte per pixel, rows top to
bottom. The textures tile seamlessly. `crates/algo` embeds them.

Frosted, the gallery's seventh texture, is procedural and has no file.
